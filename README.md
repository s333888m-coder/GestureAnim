# Gesture Animator (Kotlin / Android)

स्वाइप, टच, बैक, होम, रीसेंट्स और ऐप-ओपन पर HTML एनिमेशन इफेक्ट दिखाने वाला ऐप।

## APK बनाना
1. इस फोल्डर की सारी फाइलें अपने GitHub repo में डालें (`.github` फोल्डर समेत)।
2. Repo → **Actions** → "Build APK" → पूरा होने पर **Artifacts** से `GestureAnim-debug-apk` डाउनलोड करें।
3. zip खोलकर `app-debug.apk` फोन में इंस्टॉल करें।

## फोन में
ऐप खोलें → Accessibility सेटिंग → "Gesture Animator" ON → वापस आकर हर इवेंट कस्टमाइज़ करें।

## अपना HTML टेम्पलेट
- **तरीका 1 (सादा):** कोई भी HTML एनिमेशन चुन लें (बैकग्राउंड transparent रखें)। हर इवेंट पर वह दोबारा चलेगा; Size और Opacity ऐप से लगेंगे।
- **तरीका 2 (पूरा कंट्रोल):** अपने HTML में यह फंक्शन बनाएँ:
```js
window.onGesture = function (g) {
  // g.type  : TOUCH, SWIPE_UP, SWIPE_DOWN, SWIPE_LEFT, SWIPE_RIGHT, BACK, HOME, RECENTS, APP_OPEN
  // g.dir   : up | down | left | right | none (उंगली की दिशा)
  // g.xf, g.yf : स्क्रीन पोज़िशन 0..1
  // g.size (1.0=100%), g.duration (ms), g.color (#RRGGBB), g.opacity (0..1)
};
```
देखने के लिए `app/src/main/assets/templates/` के 4 बिल्ट-इन टेम्पलेट खोलें।

## Gesture Rules (पोज़िशन + संदर्भ + नतीजा)
ऐप में "Gesture Rules" से रूल बनाएँ। हर रूल में:
- **संदर्भ:** कहीं भी / सिर्फ होम स्क्रीन पर / सिर्फ ऐप के अंदर
- **ज़ोन:** ऊपर-बायाँ/दायाँ कोना, बायाँ/दायाँ किनारा, नीचे-बायाँ/बीच/दायाँ
- **दिशा:** ऊपर / नीचे / बाएँ / दाएँ / कोई भी
- **नतीजा:** तुरंत, या Recents / Home / Back / ऐप खुलने / Notification-QS खुलने / कोई नई विंडो खुलने पर
- **खुद क्या करे:** ज़ोन की पट्टी टच ले लेती है, इसलिए ज़रूरत हो तो Notification panel, Quick Settings आदि चुनें
- अपना अलग HTML डिज़ाइन, साइज़, टाइम, कलर, ओपेसिटी

उदाहरण 1: संदर्भ=होम, ज़ोन=ऊपर-दायाँ कोना, दिशा=नीचे, खुद करे=Quick Settings → डिज़ाइन A
उदाहरण 2: संदर्भ=होम, ज़ोन=बायाँ किनारा, दिशा=दाएँ → डिज़ाइन B
उदाहरण 3: ज़ोन=नीचे-बीच, दिशा=ऊपर, नतीजा=Recents खुलने पर → डिज़ाइन C

टेम्पलेट के `g` में `zone`, `outcome` और असली `dir` भी मिलते हैं, `xf/yf` = स्वाइप शुरू होने की जगह।

## साउंड सिस्टम
- **हर इवेंट / रूल के साथ साउंड:** ✨ इफेक्ट्स टैब → इवेंट/रूल खोलें → "🔊 साउंड" कार्ड (साउंड, वॉल्यूम, चैनल, "सिर्फ आवाज़" मोड)।
- **नोटिफिकेशन साउंड:** 🔊 साउंड्स टैब — ऐप-वार (Gmail, WhatsApp, कोई भी ऐप), टाइप-वार (कॉल/रिंगटोन, मैसेज, ईमेल, अलार्म…), पॉपअप, और डिफ़ॉल्ट। इसके लिए Notification Access चालू करें।
- साउंड स्रोत: 14 बिल्ट-इन, फोन के सिस्टम साउंड, या अपनी ऑडियो फाइल।
- ⚙️ सेटिंग्स में मास्टर ON/OFF और मास्टर वॉल्यूम।

## Xiaomi / Redmi (HyperOS) पर
ऐप के होम टैब में "Xiaomi / HyperOS" कार्ड है: App info → Allow restricted settings, Autostart ON, Battery = No restrictions, और Recents में ऐप कार्ड लॉक। इनके बिना Accessibility सर्विस थोड़ी देर बाद बंद हो सकती है।
